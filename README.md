# ⛵ Морские волки

Морской экшен для Android в 3D low-poly стиле. Вы капитан корабля на открытом архипелаге: топите пиратов пушками и тараном, собираете сундуки с золотом, выполняете задания, покупаете и улучшаете корабли.

## Возможности
- **3D-графика** на three.js: волны, острова с деревнями, маяком и причалами, корабли с парусами, взрывы, брызги, дым, пенный след.
- **Плавающий джойстик**: коснитесь экрана в любом месте и тяните палец, корабль поплывёт в эту сторону.
- **Рывок** (кнопка с парусами слева): ускорение, удар тараном с двойной силой.
- **Автоматические бортовые залпы**: пушки бьют по пиратам, которые оказываются сбоку от корабля.
- **Пираты 4 типов**: шлюп, бригантина, корсарский фрегат и Чёрный галеон (босс). Чем дальше от центра, тем сильнее враги.
- **Добыча**: сундуки с монетами и кристаллы с потопленных кораблей.
- **Задания** с наградами, указателем направления и расстоянием до цели.
- **5 портов**: заплывите в круг у причала. В порту бесплатный ремонт, верфь с 6 кораблями (от шлюпа до линкора) и 4 улучшения для каждого (корпус, паруса, пушки, заряжание, по 5 уровней).
- Гавани безопасны. Автосохранение.

## Установка
Скачайте `SeaTrader.apk` из релиза **«Морские волки (последняя сборка)»** (раздел Releases) и установите на телефон.

## Сборка
- `web/` — исходники игры (JavaScript, three.js). Команда `npm ci && npm run build` собирает `app/src/main/assets/game/bundle.js`.
- `app/` — Android-оболочка (WebView) на Kotlin.
- GitHub Actions собирает всё и публикует APK при каждом пуше.

Локально: `cd web && npm ci && npm run build`, затем `./gradlew assembleDebug` (нужен Android SDK).
