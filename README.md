# ⛵ Морские волки

Нативная 3D-игра для Android про морские сражения (Kotlin + OpenGL ES через движок [libGDX](https://libgdx.com)). Вы капитан корабля на открытом архипелаге: топите пиратов пушками и тараном, собираете сундуки с золотом, выполняете задания, покупаете и улучшаете корабли.

## Возможности
- **3D low-poly графика**: волны, острова с деревнями, маяком и причалами, корабли с парусами и пушками, взрывы, брызги, дым, пенный след.
- **Плавающий джойстик**: коснитесь экрана в любом месте и тяните палец, корабль поплывёт в эту сторону.
- **Рывок** (кнопка с парусами слева): ускорение, удар тараном с двойной силой.
- **Автоматические бортовые залпы** по пиратам, которые оказываются сбоку от корабля.
- **Пираты 4 типов**: шлюп, бригантина, корсарский фрегат и Чёрный галеон (босс). Чем дальше от центра, тем сильнее враги.
- **Добыча**: сундуки с монетами и кристаллы.
- **Задания** с наградами, стрелкой-указателем и расстоянием до цели.
- **5 портов**: заплывите в круг у причала. В порту бесплатный ремонт, верфь с 6 кораблями (от шлюпа до линкора) и 4 улучшения для каждого.
- Гавани безопасны. Автосохранение. Кнопка «Назад» ставит игру на паузу.

## Установка
Скачайте `SeaTrader.apk` из релиза **«Морские волки (последняя сборка)»** (раздел Releases) и установите на телефон.

## Устройство проекта
- `core/` — вся игра (Kotlin, libGDX): `SeaGame.kt` (логика, интерфейс), `Geo.kt` (3D-модели), `Water.kt` (шейдер моря), `Fx.kt` (частицы), `Data.kt` (корабли, враги, задания).
- `app/` — Android-модуль (`AndroidLauncher`), ресурсы и шрифт в `app/src/main/assets`.
- `desktop/` — версия для ПК для отладки: `./gradlew :desktop:run -Pdesktop`.

Сборка APK: `./gradlew assembleDebug` (нужен Android SDK). GitHub Actions собирает и публикует APK при каждом пуше.
