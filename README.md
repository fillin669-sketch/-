# ⛵ Морской купец

Торговая игра для Android. Вы капитан небольшого парусника. Плавайте между портами архипелага, покупайте товары дёшево и продавайте дорого, улучшайте корабль и за 365 дней торгового сезона станьте самым богатым купцом.

## Что есть в игре
- **8 портов** на карте архипелага, у каждого свои дешёвые и дорогие товары.
- **8 товаров**: зерно, рыба, вино, ткани, железо, специи, шёлк, самоцветы.
- **Живой рынок**: цены меняются каждый день, а крупные сделки сдвигают цену. Слухи в таверне сообщают о подорожании и подешевлении.
- **Плавания по карте**: время в пути зависит от расстояния и скорости корабля, команде платится жалованье.
- **События в море**: пираты (сражаться, бежать или откупиться), штормы, находки, попутный ветер.
- **Верфь**: ремонт, расширение трюма, новые паруса, пушки.
- **Звания** по итогам сезона, рекорд, автосохранение.

## Как установить на телефон
1. Откройте в репозитории раздел **Releases** и выберите релиз **«Морской купец (последняя сборка)»**. APK есть и во вкладке **Actions**, в последней сборке, в блоке *Artifacts*.
2. Скачайте `SeaTrader.apk` на телефон.
3. Откройте файл. Android попросит разрешить установку из этого источника: разрешите.
4. Играйте!

## Сборка
APK автоматически собирает GitHub Actions (`.github/workflows/build-apk.yml`) при каждом пуше.
Локально (нужен Android SDK): `./gradlew assembleDebug`.

Код: Kotlin, без сторонних библиотек.
- `Game.kt` — игровая логика и экономика
- `MapView.kt` — карта
- `MainActivity.kt` — экраны
- `Save.kt` — сохранение
